Folder structure:
-----------------

data-> hold all the data files
utility-> wrapper methods under helpers folder ex: api, ui, fixtures
page -> classes
test->for executing the test cases
reports-> to have timestamp and html report

Dependencies/libraries:
-----------------------

npm init playwright@latest

npm -v
